# Lux.Table (LuxStack)

TanStack Table & Virtual equivalent for .NET, Blazor, and .NET MAUI:
- **`Lux.Table.Core`**: Headless C# hierarchical tree builder (`DataListTree<T>`) with cycle detection and summary row models (`DataListRowSummary<T>`).
- **`Lux.Table`**: Full `BxDataList` component suite (`BxDataList`, `BxDataListTable`, `BxDataListGrid`, `BxDataListToolbar`, `BxDataListFilterBar`, `BxDataListPagination`, `BxDataListBulkBar`, `BxDataListColumnsMenu`, `BxDataListSavedViews`, `BxDataListExportMenu`, `AddLuxTable()`).
